= 本文档使用的实验室设置
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


下图显示了所使用的实验室设置的高级概述。两个单主机 HANA MDC 系统用于演示各种操作。HANA 系统 BM1 用于执行备份、还原和恢复操作，而 HANA 系统 QM1 用作 SAP 系统刷新操作的目标系统。HANA 系统部署在两个裸机服务器上，存储端使用两个 ASA A30 2 节点集群。第一个集群托管 HANA 系统的所有存储单元，第二个集群用作备份复制的目标。
